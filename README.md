# Guess the Weather

The app sends a request to access the API Open-Meteo, which takes a city name and turns it into coordinates (latitude and longitude), then uses those coordinates to get the city's current weather back as data in JSON format. No API keys were needed, as it is free and available for everyone. To run it, a user would open index.html in the browser.

See [prompt_log.md](prompt_log.md) for the AI tools and prompts used to build this.
